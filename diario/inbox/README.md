# diario/inbox

Coloque aqui `AAAA-MM-DD.md` com o resumo do dia do diário do Obsidian (data de Brasília).
Quando existir, o workflow `perfil-diario` usa este arquivo como fonte do `diario/AAAA-MM-DD.md` daquele dia.
Sem ele, o diário sai da atividade pública no GitHub das últimas 24h ou, sem atividade, de um tópico de `revisao.yml`.
Não escreva aqui nada de projeto privado.
